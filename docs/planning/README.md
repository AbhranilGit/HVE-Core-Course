| `sprint-plan.md` | `GitHub Backlog Manager`, via `/github-sprint-plan` | [Stage 5 — Sprint planning](../../lifecycle/05-sprint-planning/README.md) |

Unlike `docs/brds/`, `docs/prds/`, and `docs/decisions/`, this folder is **not**
an HVE Core default. HVE Core keeps its sprint planning notes under
`.copilot-tracking/github-issues/sprint/`, which is working evidence and is not
committed. This kit asks for a committed copy as well, because Stages 6, 7, and
8 all read the sprint plan and need it to survive a fresh clone.

That is why the Stage 5 prompt ends by asking for the plan to be written here
explicitly. The helper will not do it on its own.

Empty until you run Stage 5.
