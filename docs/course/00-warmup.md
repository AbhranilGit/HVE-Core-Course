# Module 0 — Warm-up (optional)

Practice one tiny RPI cycle before PulseBoard work.

## Goal

Create a throwaway check that `docs/course/` contains a `README` or module files — using research → plan → implement, not “just write the script.”

## Prompt (VS Code + hve-core-all)

```text
/rpi-research

Research what's needed to add a tiny Python script that lists markdown files
under docs/course/ and exits 0 if at least one exists. Note repo conventions.
```

Then `/clear`, then `/rpi-plan` with your findings, then `/clear`, then `/rpi-implement`.

## Cursor / coach path

Tell the coach: “Run Module 0 warm-up with me” and we will walk the same phases in chat, writing artifacts to `.copilot-tracking/`.

## Exit criteria

- You used separate research / plan / implement steps (or RPI Agent once)
- A durable research or plan file exists under `.copilot-tracking/`
- You understand why `/clear` (or a fresh chat) between phases matters
