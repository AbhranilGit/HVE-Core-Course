# Reviews

The committed verdicts on whether this product does what it promised.

| File | What it answers |
| --- | --- |
| `sprint-1-review.md` | Did Sprint 1 deliver its definition of done? |
| `sprint-2-review.md` | Did Sprint 2? |
| `code-review.md` | Is the code itself correct, safe, and adequately tested? |

Produced in [Stage 7 — Review](../../lifecycle/07-review/README.md). Empty until
you run it.

These are summaries. The full evidence the reviewers worked from lives under
`.copilot-tracking/reviews/`, which is not committed by default — so anything
you will still want in six months belongs in these files, not there.

Every defect recorded here should carry a decision: fix now, fix later, or will
not fix. A finding with no decision is an open question pretending to be a
record.
