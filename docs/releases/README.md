# Releases

Your release paperwork lands here, one set per version.

| File | What it holds |
| --- | --- |
| `v0.1.0-release-evidence.md` | The proof it was ready to ship: every acceptance criterion, where its evidence lives, and the test run |
| `v0.1.0-release-notes.md` | What shipped, how it was checked, and what was deliberately left out |

Produced in [Stage 8 — Delivery](../../lifecycle/08-delivery/README.md). Empty
until you run it.

`v0.1.0` is this template's default first version. If your project versions
differently, use your own scheme and keep the filenames consistent with it.
