## MVP capabilities shipped

PulseBoard `v0.1.0` ships the thin-slice MVP for local-first daily status sharing:

* Display-name identity for attribution (no SSO or OAuth)
* Create or update one status per display name per day with `doing`, `blocked`, and `next`
* Today board view showing team rows for the current instance day
* Blocker visibility through `blocked` field text on board rows
* Local SQLite persistence so data survives restarts on the same DB file
* Documented local operator path for startup and testing
